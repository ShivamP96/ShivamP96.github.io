# [Score Tracker](https://shivampatel.ca/score-tracker/)

[Click Here to see the project!](https://shivampatel.ca/score-tracker/)

The Score Tracker Project is a simple tracker for when you want to play 1 on 1 sports or team 1 on 1 sports!
Use this Project to your own liking!

![preview](/assets/img/score-tracker.gif)

## Tech Stack

    - TypeScript

## Motivation

I built this WebApp to create a personalized way to track game scores while playing volleyball with my friends. It provides a simple and efficient way to keep score, ensuring a seamless playing experience.
